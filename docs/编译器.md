# 编译器（compiler-core）

`compiler-core` 模块负责将模板字符串编译为渲染函数。其核心流程包括：解析（parse）、转换（transform）、代码生成（codegen）。

## 主要流程

1. **解析（parse）**：将模板字符串解析为 AST（抽象语法树）。
2. **转换（transform）**：对 AST 进行各种转换（如表达式处理、静态提升等）。
3. **代码生成（codegen）**：将转换后的 AST 生成渲染函数代码。

## 主要 API

- `parse(template)`：解析模板为 AST。
- `transform(ast, options)`：对 AST 进行转换。
- `generate(ast)`：生成渲染函数代码。
- `compile(template)`：一站式编译入口，返回渲染函数。

## 示例

```js
import { compile } from 'mini-vue/compiler-core'

const { code } = compile('<div>{{ msg }}</div>')
console.log(code)
```

更多编译器相关示例可参考 `packages/vue/src/examples/compiler/` 目录。
